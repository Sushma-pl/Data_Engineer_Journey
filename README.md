# Data Engineer Journey 🚀

Hey! I'm Sushmita, and this is my personal learning repository for Data Engineering.

I'm documenting everything I learn — from fundamentals to advanced concepts — in a way that's easy to follow for anyone starting or growing in the data engineering space. My goal is to keep this honest, practical, and community-friendly.

---

## Why this repo?

Two reasons:

1. **For me** — writing things down forces clarity. If I can't explain it simply, I don't understand it well enough.
2. **For you** — if you're learning data engineering too, I want these notes to feel like a conversation, not a textbook. Real confusion, real breakthroughs, real examples.

---

## My Current Focus

🐳 **Docker** — learning how to containerize data pipelines and services for a real streaming project.

---

## How to Navigate

Each topic gets its own folder. Inside each folder there's a `README.md` that lists all the notes in order — start there.

```
Data_Engineer_Journey/
├── README.md               ← you are here
│
├── docker/                 ← current focus
│   ├── README.md
│   ├── 01_what_is_docker.md
│   └── ...
│
└── _template.md            ← note template (for contributors or my own reuse)
```

More folders will be added as I grow — streaming, SQL, Python, databases, cloud, and more.
